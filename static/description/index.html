View History Logger

Track form views and reopen records quickly

Logs the model and record id whenever a user opens a form view. A new systray icon shows recent items in a dropdown so users can jump back to the record in one click.

Key Features

Automatic Logging

Store view history on every form view open.

Systray Dropdown

Quick access to recently viewed records.

User Opt-In

Toggle logging per user in Preferences.

How It Works

  • - Open any form view to create a history entry.
  • - Click the history icon in the top-right systray to view recent items.
  • - Select an item to open the form view directly.
